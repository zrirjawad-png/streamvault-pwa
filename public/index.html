Install StreamVault PWA

        
      

      

        When hosted over HTTPS or localhost, this app registers a Web App Manifest and Service Worker with the Web Share Target API—allowing you to share video links directly from other apps into StreamVault.
      

      

        
Chrome / Edge (Desktop & Android): Click the install icon in the address bar or choose Install App from the browser menu.

        
Safari (iOS / iPadOS): Tap the Share button and select Add to Home Screen.
